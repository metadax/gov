# ECONX - Soluções em Energia Sustentável e Tecnologia

A ECONX é uma empresa focada em oferecer soluções em energia sustentável e tecnologia para um futuro mais verde. Nosso objetivo é fornecer serviços de energia solar por assinatura, compensação das emissões de carbono e, futuramente, um banco digital que recompensará práticas sustentáveis.

## Especificações do Projeto

- O site é altamente responsivo e tem uma página única.
- As cores utilizadas são:
  - Fundo: #343434
  - Detalhes principais: #FFFFFF
  - Detalhes secundários e botões primários: #03983D
  - Detalhes terciários e botões secundários: #006DFF
- A fonte utilizada em todo o site é a 'Inter'.
- O favicon é o arquivo `assets/icons/icon.svg`.
- A logo da página é o arquivo `assets/images/econex.png`.
- O site é otimizado para mecanismos de busca (SEO).
- Foram utilizados ícones do Font Awesome para cada solução.
- O menu está centralizado e alinhado à direita, com responsividade para telas menores.
- Animações foram adicionadas aos botões e itens do menu para maior atratividade.

## Estrutura do Projeto

- `public/index.html`: Arquivo HTML principal.
- `assets/styles/index.css`: Arquivo CSS para estilização.
- `assets/script/index.js`: Arquivo JavaScript para interatividade.
- `assets/icons/icon.svg`: Arquivo SVG do favicon.
- `assets/images/econex.png`: Arquivo PNG da logo.
- `assets/images/DESKTOP - ECONX.png`: Imagem de fundo da seção hero.

## Conteúdo

O conteúdo do site é baseado nas informações fornecidas pela Ayron Energia (https://www.ayronenergia.com.br), adaptado para se adequar aos serviços e propostas da ECONX. Informações adicionais foram incluídas para enriquecer cada solução apresentada.

## Arquivos Adicionais

- `robots.txt`: Arquivo para configuração dos motores de busca.
- `sitemap.xml`: Arquivo de mapa do site para ajudar na indexação pelos motores de busca.

## Responsividade

O site é totalmente responsivo, adaptando-se a diferentes tamanhos de tela. O menu se ajusta para uma visualização vertical em dispositivos móveis.

## Animações

Foram adicionadas animações sutis aos botões e itens do menu para melhorar a experiência do usuário e tornar o site mais atrativo.

## Solução de Problemas

Se o arquivo CSS não estiver sendo carregado no deploy, verifique os seguintes pontos:

1. Certifique-se de que o caminho para o arquivo CSS no HTML está correto: `../assets/styles/index.css`.
2. Verifique se o arquivo CSS existe no local especificado.
3. Assegure-se de que todos os arquivos estão sendo incluídos no processo de deploy.
4. Verifique as configurações do seu servidor web para garantir que ele está configurado para servir arquivos CSS corretamente.

## SEO e Indexação

O arquivo `sitemap.xml` foi atualizado para incluir todos os caminhos relevantes do site, incluindo arquivos CSS, JavaScript, imagens e ícones. Isso ajuda os motores de busca a indexar corretamente todo o conteúdo do site e pode melhorar o desempenho nos resultados de pesquisa.

O domínio utilizado no sitemap é econx.vercel.app, que é o domínio atual do deploy.

Certifique-se de que o arquivo `sitemap.xml` está localizado na raiz do seu site e que está referenciado no arquivo `robots.txt`.
